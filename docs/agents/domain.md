# Domain Docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions in `docs/adr/` when they exist.
- If either is absent, proceed without treating the absence as an issue.

## File structure

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## Vocabulary

Use the terms defined in `CONTEXT.md` for domain concepts in issues, plans, code, and tests. If a needed term is missing, record the vocabulary gap for domain modeling rather than silently introducing a synonym.

## ADR conflicts

If a proposed change contradicts an existing ADR, identify the ADR explicitly before proceeding.
